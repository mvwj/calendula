# Calendula development history

The public repository started with a reviewed source snapshot on October 30, 2026. The earlier implementation history was recovered and attributed in the separate private archive. This public record summarizes the milestones without publishing private Git objects, local fixtures or session transcripts.

- October 3–4, 2026. Design and browser prototype for a private agenda, reviewed imports and trip planning. Native Flutter work established Android and Windows targets, encrypted local storage and reviewed imports. The first native Git snapshot consolidated earlier development. Intermediate source recovered from recorded patches is held in the private archive.
- October 4–5, 2026. Series deletion, read-only mail, Android share imports, encrypted sync, multi-account sign-in, local routing and setup transfer. Recorded phone and desktop evidence varies by feature and build.
- October 8–9, 2026. Event places and automatic departure agenda, followed by a recorded 0.2.6 device check.
- October 30, 2026. Widget preview changes, a bounded phone check, and the reviewed English public release. The saved locked-screen run ended in a crash. See [verification](VERIFICATION.md) for the scope of past checks.
